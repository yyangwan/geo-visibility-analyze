- `value_replay.py`：离线检查冻结输入 hash、逐字分段、完整偏移、逐次观测和预测状态。拒绝空输入、缺失状态、篡改、覆盖缺口；报告明确 `semantic_quality=not_evaluated`、`release_eligible=false`。
- `semantics.py`：明确四个顶层数组及属性数组类型，禁止把缺字段/null 当成已检查的空结果。只允许非空属性字符串包成单元素列表这一种无损格式修正，并记录修正路径；对象、混合类型及非法位置仍失败。只修正唯一原文片段的偏移，不生成提及或排名。提示词和流水线签名已变更。
- `provider_failures.py` / worker：分析请求的 402/401/403/400 等配置或账户错误直接保留明确原因并停止自动重试；429/5xx 保留有限重试。已保存原文及检查点不删除，不切换到 Higress 或其他密钥。
