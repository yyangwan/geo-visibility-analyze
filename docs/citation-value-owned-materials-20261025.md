# A03 我方材料版本与事实来源

本轮完成本地技术实现，尚未部署。对应门户已确认的 v3 原型中“引用来源 → 我方材料与事实”操作流。未新增数据库表、历史迁移或模型调用；沿用 R00 最新空库结构和现有不可变对象存储接口。

## 已实现的客户操作

1. 为当前登记的自有品牌保存材料：公开 HTTP(S) URL 或纯文本。两者同时提供时，保存用户提供的文字，URL 作为出处参考；仅 URL 时由后端 worker 取得正文。
2. 同一材料按逻辑资产键追加版本，不覆盖已取得原文。记录品牌、固定用途 `audit_reference`、文字/压缩对象校验、取得时间、质量与快照。
3. 查看取得中、受限、失败及重试状态。仅允许最新、尚未取得且无活动任务的 URL 版本人工重试；不绕过登录、验证码或采集限制。
4. 具名审核当前版本的归属、适用范围和核实依据。核实整份材料不等于批准其中全部产品说法。
5. 从已核实原文选择逐字事实，明确范围、依据和生效/截止时间，单独批准。批准、换版和撤回可回查，过期、待生效、需复核、已撤回和被替代分别返回。

门户遵循既有角色和完整内容洞察能力守卫。材料写入前先同步服务端品牌登记上下文；读取不触发采集、模型、上下文写入或内容额度预占。后端同样独立验证项目范围、写入角色和当前自有品牌身份。

## 证据边界

- 自有材料不创建 `CitationObservation`、`ClaimReview` 或回答中的品牌提及。没有任何审计或发现实体时也可以在项目 API 登记材料并批准事实；门户入口仍位于审计来源页面。
- 两种事实来源共用 `FactSource` 联合类型：`citation_review` 与 `owned_asset_revision`。自有材料证据拥有真实项目、材料版本、核实事件、正文 hash 和 Unicode code point 区间，`run_id`/`segment_id` 可空；观察证据仍必须有真实 Run 与片段。
- 原文、压缩对象和正文 hash 分别校验；材料事实批准及授权来源导出实际读取对象。模型不能选择私有对象路径、授予品牌归属或批准事实。
- 新材料版本、撤销核实、核实事件变化、品牌转为竞品、事实换版/撤回、有效期及证据完整性都参与可用性判断。历史记录保留，不静默转移至另一材料。
- Run 冻结当前材料版本/状态/核实事件/用途及事实来源。修改只通知生成新分析修订，不改写旧 manifest。
- 未提供/未取得材料属于未知，不能证明产品缺少该能力；材料也不能补写成回答已经说过的内容或提高可见性分数。

## API

所有路径以 `/api/intelligence` 为前缀，另有门户受控代理 `/api/integration/intelligence/materials`。

| 方法与路径 | 作用 |
|---|---|
| GET/POST `/projects/{pid}/owned-assets` | 分页读取 / 登记新材料或版本 |
| GET `/projects/{pid}/owned-assets/{id}`、`/text` | 版本状态 / 已保存原文 |
| GET `/projects/{pid}/owned-assets/{id}/facts` | 同一逻辑材料所有版本的事实历史 |
| POST `/projects/{pid}/owned-assets/{id}/verify` | 独立材料审核 |
| POST `/projects/{pid}/owned-assets/{id}/retry` | 有限人工重新取得 |
| POST `/projects/{pid}/owned-assets/{id}/facts` | 具名事实批准 |
| POST `/facts/{id}/withdraw` | 追加撤回记录，复用现有入口 |
| GET `/facts/{id}/source` | 仅导出当前有效事实的统一来源类型 |

登记每项目最多 200 个逻辑材料，单份纯文本最多 200,000 code points；材料列表每页至多 100，门户每页 50。单材料事实历史当前返回完整历史，并未实现历史分页。

## 并发与失败处理

项目 head 行锁串行化材料写入；材料、事实及活动任务校验使用数据库当前锁定读，并刷新 ORM 已加载对象。MySQL 的旧 REPEATABLE READ 快照不会因为拿到 head 锁自动刷新，不能用先前普通 SELECT 的值做审核 CAS。

登记、核实、重试、事实批准和撤回都校验幂等键及精确载荷/操作者。相同重试返回既有结果，冲突载荷或旧版本返回 409。worker 沿用现有租约/fencing、公开 IP 固定、有限重试及不可变保存，过期租约不能提交。终止失败对材料保留原因并通知新修订。

门户不确定写入保留同一幂等请求并锁定编辑；已知保存成功后的列表刷新失败不冒充“写入未知”。抽屉异步结果绑定材料/核实版本，避免换材料后显示上一份原文或事实。
