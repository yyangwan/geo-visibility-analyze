## 已实现的防护

1. required 数组缺失、错误类型或截断输出明确失败；仅字符串 attributes 转单元素数组这一无损形态修复有审计记录。没有空数组成功兜底。
2. 字符 offset 只有在 quote 全文唯一且逐字匹配时才修复并记录；重复名字不定位到第一次。名称不在引文、歧义/缺失片段保留 rejected candidate，整条输入不会被丢弃。
3. 处理覆盖与证据片段质量分开。完整文字已处理且所有局部拒绝有记录时，局部问题只阻断相关品牌的缺席/完整评价；无从定位主体的问题仍保守阻断。有效正向提及保留出现维度，未知推荐/理由/位置不补零、不重新分配权重。
4. 快照保存不可用文字的质量记录。验证页、空内容、严格模式识别的疑似无正文导航页仍保留原始对象，但不送入正文抽取、来源证据关系或正文出现率分母。短文字和较长文字都不宣称原文章完整；广告声明单独保留，不推导为独立第三方认可。
5. 修复正文出现指标将解压文字 hash 与 gzip 对象 hash 混比的问题。正文一致性使用 `body_hash`，对象读取继续验证 `text_sha256`。
